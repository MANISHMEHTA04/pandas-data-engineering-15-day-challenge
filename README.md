A project-based Pandas learning journey focused on practical Data Engineering interview preparation.

## Goal

Build interview-ready Pandas skills through 15 Data Engineering mini-projects covering data cleaning, filtering, aggregation, joins, timestamps, CDC, incremental ETL, SCD Type 2, nested JSON, and production pipeline concepts.
